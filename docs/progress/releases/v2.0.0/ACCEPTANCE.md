- 旧 UI、网络模块源码和安装残留已清理，旧网络守护已停止，三个旧快捷方式已移除。被删除文件及原未提交改动保存在仓库外私有恢复备份中。

## 发布与兼容边界

本地 `main`、`v2.0.0` 标签和 GitHub Release 使用同一提交；旧 Git 标签及历史发行作为恢复来源保留。当前工作树移除旧版发行目录，历史内容仍可从对应标签读取。

运行时就绪不等于网络健康。未来真实产品升级及超过五分钟的服务端流稳定性不属于已通过的验收；新版安装布局变化需要重新检查兼容性。
