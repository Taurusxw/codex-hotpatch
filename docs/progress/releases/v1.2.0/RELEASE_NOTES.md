# codex-hotpatch v1.2.0

发布日期：2026-09-17。非官方、用户级可回退补丁；不替换 Codex Desktop 或 CLI，不修改 `app.asar`、任务数据库或会话 JSONL。

## 变更

- 网络补丁 **1.14.21**：适配更新后的桌面运行时缓存与启动恢复；保留按核心归属的网络观察、安装失败回滚及显式代理持久停用。存在 `https-only.disabled` 时不再接管或恢复用户的 provider，也不启动配置解析探测。两个停用标记独立生效。
- 子智能体状态 **1.3.22**：合并活动、归档和持久完成证据，只读使用父子线程元数据匹配新版界面；统一摘要与列表状态。监听目录先解析为真实路径，修复 Windows 8.3 短路径触发 Node/libuv 原生断言崩溃。
- 归档侧栏过滤 **0.2.2**：只读本地线程索引冷启动种子、累计局部归档批次、过滤过期孤儿占位条目并处理页面重载；不删除任务或修改归档状态。
- 界面总监督 **1.0.3**：独立隐藏启动 watcher、清理所属孤儿 injector、指数退避；启用本地 DevTools 时核验 renderer 装载。
- PowerShell 源文件统一 UTF-8 BOM，修复 Windows PowerShell 5.1 对中文字符串的解析兼容问题；补齐贡献文档的全部测试命令。
- 移除旧 `reasoning-labels` 组件源码，不再作为本发行版的安装组件。历史源码仍可从 v1.0.0 获取。

## 安装与回退

使用根目录 README 中各组件的 `Install` 命令独立升级。升级前保存现有安装文件与用户配置；本机运行态、凭据和备份不进入发行资产。网络停用标记应保留，不要为了更新删除它们。

界面补丁需要本地 DevTools；官方入口未启用该端口时只能安装待命，不能据此声称当前窗口已经修复。由用户选择正常退出后从带 DevTools 的入口启动，不强制重启活动任务。

`Uninstall` 用于退出组件管理，并不等于精确恢复升级前的用户配置；精确回退应使用升级前私有备份。不要将配置备份或本机日志上传 GitHub。

## 验证与限制

发布验证见 [ACCEPTANCE.md](ACCEPTANCE.md)。固定线路上的短请求与约 115 秒 HTTP 请求曾完成，尚未证明超过五分钟的长流稳定；历史 HTTP 流中断没有被证明根治。增加重试次数、禁用 WebSocket 或 watcher 存活都不能作为网络修复证明。

不改变用户 VPN 节点。显式代理停用后没有可自动切换的第二条获准线路；现存任务不会被热切换 provider。未来 Codex 更新若改变运行时或 renderer 契约，仍需重新验收，不能保证每次更新零错误。
